# ScamLens

Ứng dụng tiếng Việt kiểm tra dấu hiệu đáng ngờ trong tin nhắn, URL và tra cứu báo cáo đã kiểm duyệt.

Mã nguồn nằm trong [`scamlens/`](scamlens). Xem [hướng dẫn cài đặt và sử dụng](scamlens/README.md) hoặc [triển khai Railway](scamlens/docs/railway.md).

```sh
cd scamlens
npm ci
npm run demo
```

Stack: React, TypeScript, Vite, Tailwind CSS, NestJS, PostgreSQL và TypeORM. Phân tích theo quy tắc có trọng số, không yêu cầu API key.
